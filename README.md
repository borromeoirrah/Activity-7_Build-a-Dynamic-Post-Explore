# Activity-7_Build-a-Dynamic-Post-Explore

===== Dynamic Post Explorer =====
- This webpage displays posts from the JSONPlaceholder API.
- Users load posts by clicking the 'Load Posts' button but if loading the posts fails, a 'Retry' button appears so users can try again.

===== Programming Language used: =====
- HTML
- CSS
- JavaScript

===== This webpage has features that: =====
- Fetches posts from an external API.
- Displays the first five posts.
- Shows loading, success, and error messages.
- You can retry loading fails.
